  - __(PCT-21 Connector):__ This connector is for the gnd line combining all the negative current to the same spot
  - __(D1-2):__ For this robot’s power distribution system we use a single battery pack, that split into 2 separate branches, one to the step-down to power the Pi, and another one straight to the Arduino
