The Main Base is the robot’s main structural layer. The Raspberry Pi 5 is mounted low to reduce height, simplify cable management, and keep the camera’s view clear.

It also has mounting points for the Servo Bracket and Motor Mount, keeping the steering servo and motors aligned and balanced. Connection points allow the next layer to be securely attached.

OR 

The Main Base is the main part that holds the robot’s components together. It supports the Pi Base, Uno Base, motors, and steering system. Its mounting points are arranged to keep the parts aligned, balanced, and securely connected, creating a strong overall structure for the robot.
